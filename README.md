# ai-physics-activities
בדף זה נמצא אתר עזר למורה לפיזיקה, הדף מרכז מנתח את גבולות חומר הלימוד היום ומציע פעילויות בינה מלאכותית מתקדמות
משימות מורכבות יותר ובעלות ערך חדש, מה שלא ניתן להגיע אליהן ללא הבינה.
רצוי שהתלמידים יתנסו בתרגילים אלו לאחר שהידע הפיזיקלי והידע איך לדבר עם הבינה ידוע להם
קחו בחשבון שזו גרסה ראשונית רעיונית שלא עברה תיקוף.
